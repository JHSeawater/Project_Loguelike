# Grave of the Fallen

TypeScript, Phaser 3, Vite로 구성한 브라우저용 2D 액션 로그라이크입니다. 게임 제목은 가제입니다.

현재 검증 환경은 Node.js 22.22.0, npm 10.9.4이며, 의존성 버전은 Phaser 3.90.0, Vite 8.3.4, TypeScript 7.0.2입니다.
`npm test`는 TypeScript 파일을 Node에서 직접 불러오므로 Node.js 22.18 이상이 필요합니다. Node.js 23을 사용한다면 23.6 이상이 필요합니다. Vite의 Node.js 요구 사항은 `^20.19.0 || >=22.12.0`입니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 개발 서버는 Ctrl+C로 종료합니다.
PowerShell에서 스크립트 실행 정책 때문에 npm이 차단되면 `npm.cmd`로 실행하세요.

## 빌드

```sh
npm run build
npm run preview
```

`build`는 TypeScript 타입 검사 후 Vite 프로덕션 빌드를 수행합니다.
결과물은 `dist/`에 생성됩니다. 미리보기 주소는 터미널에 표시됩니다.
`npm test`로 이동·충돌·전투·경험치·레벨업 보상·직업·스프라이트 적용 회귀 검사(`tests/`)를 실행합니다. 스프라이트 가공 검사는 Windows에서만 실행되고 다른 환경에서는 건너뜁니다.

## 스프라이트 재가공

```sh
npm run sprites:process
```

`sprite/`의 제공 원본을 `sprite/profiles/` 설정에 따라 가공해 `public/assets/sprites/`에 씁니다. Windows PowerShell이 필요하며, 절차는 [스프라이트 가이드](docs/SpriteGenerationGuide.md) 13절을 참고하세요.

## 구성

- `src/main.ts`: Phaser 설정과 게임 장면(HUD·보상 선택창·게임 종료 화면)
- `src/menu-scenes.ts`: 타이틀과 캐릭터 선택 장면
- `src/battle.ts`: 전투 시뮬레이션(이동·생성·공격·투사체·보스·가호·경험치·보상·직업 능력·소환물)
- `src/battle-config.ts`: 전투·적·직업·특기 수치
- `src/battle-geometry.ts`: 전투 판정용 사각형·선분 계산
- `src/navigation.ts`: 적의 장애물 우회 경로 탐색
- `src/world-art.ts`: 고정 시드로 생성하는 도트 바닥과 고딕 울타리 텍스처
- `src/dungeon.ts`: 도트 비석·바위·나무 잔해와 고정 장애물 배치
- `src/dungeon-layout.ts`: 고정 시드 기반의 불규칙 분산 배치와 통로 확보
- `src/collision.ts`: 사각형 충돌과 축별 미끄러짐 이동
- `src/render-depth.ts`: 월드 개체에 공통으로 사용할 발밑 기준 그리기 순서
- `src/experience.ts`: 레벨업 필요 경험치와 경험치 누적·연속 레벨업 계산
- `src/rewards.ts`: 공통 보상과 직업 특기 목록, 보상에 따른 능력치 계산과 선택지 구성
- `src/sprite-animation.ts`: 스프라이트 설정, 투사체·구슬·효과의 외형 선택, 게임 시간 기준의 공통 애니메이션 재생기
- `src/sprite-view.ts`: Phaser 스프라이트 생성과 재생 상태 적용
- `src/warlock-animation.ts`: 기존 워록 호출부와 테스트를 위한 호환 진입점
- `src/style.css`: 화면 배치
- `sprite/`: 사용자 제공 원본(`used/`), 가공 설정(`profiles/`), 가공 보고서(`reports/`)
- `scripts/`: 스프라이트 공통 가공기
- `public/assets/sprites/`: 가공해 게임에서 불러오는 PNG와 메타데이터
- `docs/`: 분야별 개발 지침, 설계 결정 기록, 스프라이트 가이드
- `tests/`: 이동·충돌·전투·성장·직업·스프라이트 회귀 검사
- `tsconfig.json`: TypeScript 엄격 타입 검사 설정

게임 내부 해상도는 1280×720이며 브라우저 크기에 맞춰 비율을 유지합니다.
게임 월드는 3000×3000이며, 판정 몸체가 40×40인 플레이어가 월드 중앙에서 시작합니다.
바닥은 어두운 흙, 죽은 풀, 작은 마른 가지가 자연스럽게 섞인 도트 지형입니다.
이전 확인용 격자 대신 지형 무늬로 카메라 이동을 확인할 수 있습니다.
월드 네 변에 두께 50픽셀의 고딕 철제 울타리와 석재 모서리 기둥이 있습니다.
장식은 코드로 생성되며 외부 이미지를 불러오지 않습니다.
WASD 또는 방향키를 누르고 있는 동안 직업별 이동속도로 이동합니다.
대각선 속도는 수평·수직 이동과 같으며, 키를 놓으면 즉시 멈춥니다.
플레이어 사각형 전체가 울타리 안쪽에서 멈추며, 울타리 위에 올라가거나 넘을 수 없습니다.
바닥의 작은 풀과 가지는 통과할 수 있는 장식입니다.
깨진 비석, 바위, 그루터기, 쓰러진 나무 등 80개 장애물은 통과할 수 없습니다.
장애물은 고정 시드로 맵 전체에 불규칙하게 분산되며 다시 실행해도 위치가 유지됩니다.
장애물 사이에는 최소 145픽셀 간격을 두고, 시작점 반경 340픽셀 공터와 십자 통로, 외곽 순환로를 비워두었습니다.
장애물에 닿으면 막힌 방향만 멈추며 옆으로 이동할 수 있습니다.
온전한 비석과 십자가 비석은 위쪽 충돌 범위를 20픽셀 줄여 상단 뒤로 일부 들어갈 수 있습니다.
마른 나무는 너비 12.5%, 높이 25% 커졌으며 위쪽 충돌 범위를 28픽셀 줄여 가지 뒤로 지나갈 수 있습니다.
일부 장애물은 좌우 반전되어 표시되며, 비대칭 그림도 충돌 범위와 맞도록 위치를 보정합니다.
발밑의 월드 Y 좌표로 그리기 순서를 정하므로 뒤의 캐릭터는 비석에 가려집니다.
플레이어·적·소환물은 같은 장애물 충돌 데이터를 사용하고, 플레이어·적·소환물·경험치 구슬은 `getFootDepth` 기준으로 그리기 순서를 정합니다. 끌려오는 경험치 구슬과 투사체는 장애물을 통과합니다.
대각선과 긴 프레임 이동도 짧은 구간으로 나누어 장애물 통과를 방지합니다.
카메라는 플레이어를 화면 중앙에서 추적하며 월드 바깥을 보여주지 않습니다.
월드 경계 근처에서는 카메라가 멈추므로 플레이어가 화면 중앙에서 벗어날 수 있습니다.
현재 월드와 장애물은 코드로 만든 도트 텍스처를 사용하고, 직업·좀비·적·투사체·경험치 구슬·전투 효과는 사용자가 제공한 이미지를 가공한 스프라이트로 표시합니다. 범위 원·보스 경고 같은 판정 표시와 HUD는 Phaser 도형으로 그립니다. BGM·효과음은 아직 적용하지 않았습니다.

## 현재 전투 구현

`npm run dev` 실행 후 타이틀 화면에서 Enter·Space·클릭으로 시작하고, 캐릭터 선택 화면에서 직업을 고릅니다.
워록은 화면 안의 최근접 적을 향해 투사체를 자동 발사하고, 데스 나이트는 주변 반경 안의 적을 모두 자동으로 벱니다.
네크로맨서는 투사체를 자동 발사하며, 죽은 적이 일정 확률로 좀비가 되어 함께 싸웁니다.
WASD·방향키 이동 중에도 공격하며, 적은 화면 밖에서 생성되어 장애물을 우회해 접근합니다.
적은 병사·기사·성기사·궁사·마법사·광신도·석궁병·사제 8종이며 각자의 스프라이트로 표시하고, HUD 범례에는 종류별 표시 색으로 이름을 보여 줍니다.
적은 게임 시간이 지날수록 더 자주, 더 많이 나오며 광신도 무리와 포위 웨이브도 등장합니다. 규칙과 수치는 [적 지침](docs/Enemy/AGENTS.md)을 참고하세요.
게임 시간 5분에는 보스 성기사단장이 등장해 정해진 순서로 범위 공격·소집·방벽을 사용하며, 처치하면 보스 전용 보상을 고릅니다.
게임 시간 2분부터 2분마다 적 체력·이동속도·공격력 중 하나를 강화하는 가호를 반드시 선택합니다. 보스 보상·가호·레벨업이 겹치면 그 순서로 선택창이 열립니다.
체력·생존 시간·적 수·처치 수는 화면 왼쪽 위에서 확인할 수 있습니다.
사망하면 게임이 종료되며 Enter·클릭으로 캐릭터 선택 화면으로 돌아가 다시 시작합니다.
직업별 능력치·패시브·특기는 [직업 지침](docs/Classes/AGENTS.md)을 참고하세요.

적을 처치하면 그 자리에 경험치 구슬이 떨어집니다. 플레이어의 획득 반경 안에 들어온 구슬은 플레이어에게 끌려와 닿으면 획득됩니다.
경험치가 쌓이면 레벨이 오르며 체력 바 아래의 경험치 바와 `Lv` 표시로 확인합니다. 게임 종료 화면에도 최종 레벨이 표시됩니다.
규칙과 수치는 [성장 지침](docs/Progression/AGENTS.md)을 참고하세요.

레벨이 오르면 게임이 일시정지되고 보상 선택지 3개가 나타납니다. 마우스 클릭이나 숫자키 1~5로 하나를 고르면 효과가 적용되고 게임이 이어집니다.
공통 보상은 공격력·공격 속도·최대 체력·이동속도·투사체 속도·획득 반경 강화, 선택지 추가(최대 5개), 체력 회복, 영혼 흡수(경험치 획득량 증가)이며, 고른 직업의 특기도 같은 선택지에 나옵니다.
보상은 이번 게임에서만 유지됩니다. 효과량과 최대 중첩은 [성장 지침](docs/Progression/AGENTS.md)을 참고하세요.

전투 공통 수치는 [전투 지침](docs/Combat/AGENTS.md), 설계 결정의 경위는 [결정 기록](docs/Decisions.md)에 정리했습니다.
