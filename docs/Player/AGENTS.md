# 플레이어 개발 지침

[루트 개발 지침](../../AGENTS.md)과 함께 적용한다. 플레이어 고유 규칙은 이 문서에서 관리하며, 적의 생성·행동·피격 규칙은 [적 지침](../Enemy/AGENTS.md)을 따른다. 초기 설정을 위임한 항목은 구현 시 값을 정해 기록하고, 미확정 항목은 임의로 확정하지 않는다.

## 설계 방향

- 향후 플레이어의 스탯과 능력은 직업마다 다르게 구성한다.
- 현재는 직업별 차이를 적용하지 않고 아래 초기 능력치와 자동 공격 방식으로 고정한다.
- 직업 시스템이나 추가 능력은 별도 요청 없이 구현하지 않는다.

## 현재 고정할 초기 능력치

| 항목 | 값 및 규칙 |
| --- | --- |
| 체력 | 100 |
| 공격력 | 10 |
| 공격 방식 | 투사체 자동 공격 |
| 사거리 | 중심이 현재 화면 안에 있는 적을 공격 대상으로 삼는다. |
| 크기 | 1 = 현재 플레이어 사각형인 40×40픽셀 |
| 공격 간격 | 0.5초 = 초당 2회 |
| 피격 간격 | 3초 |

위 값은 현재 고정할 설계 기준이다. 공격 간격과 피격 간격은 서로 다른 항목으로 관리한다.

## 자동 공격

### 대상 선택

- 살아 있고 공격 가능한 적 중에서 중심이 실제 카메라의 월드 표시 범위(`camera.worldView`) 안에 있는 적만 새 공격 대상으로 삼는다.
- 화면 안의 후보 중 플레이어와의 직선거리가 가장 가까운 적을 우선한다. 거리 제곱으로 비교해도 된다.
- 선택한 적의 중심이 화면 밖으로 나가거나 적이 사망·제거되면 해당 적을 향한 새 공격을 중지하고 화면 안의 다른 최근접 적을 선택한다.
- 후보가 없으면 발사하지 않는다. 거리 동률 처리만 아래 확인 항목으로 남긴다.

### 공격 시점과 이동

- 적이 화면 안에 들어와 공격 대상이 생기면 자동 공격을 시작한다. 첫 발사는 공격 가능한 시점에 수행하며 이후 공격 간격은 0.5초다.
- 별도의 공격 입력 없이 공격하며, 이동 중에도 자동 공격을 유지한다.
- 대상 교체나 화면 진입·이탈로 공격 간격을 무시하고 연속 발사하지 않도록 한다.
- 대상이 없을 때의 공격 대기·타이머 관리 방식은 리소스 최적화를 기준으로 정한다. 발사를 누적해 나중에 한꺼번에 쏘지 않는다.

### 투사체

- 한 번에 **1개**를 발사하며 **비유도·비관통**을 기본으로 한다.
- 발사 시 정한 방향으로 이동하며 발사 후 대상을 따라 방향을 바꾸지 않는다.
- 투사체는 장애물에 막히지 않는다. 몸체의 이동 충돌과 투사체의 장애물 통과를 구분한다.
- 첫 번째로 유효하게 맞힌 적에게 공격력 10의 피해를 적용하고 소멸시킨다. 같은 투사체가 적을 중복 타격하거나 여러 적을 관통하지 않는다.
- 이미 발사한 투사체는 화면 밖에서도 적을 맞힐 수 있다. 카메라 밖으로 나갔다는 이유만으로 삭제하거나 피해 판정을 끄지 않는다.
- 투사체 속도·크기·수명 등은 장르에 맞는 초기값을 정해 테스트로 조정한다. 화면 밖 피해 규칙을 지키면서 수명이 끝난 투사체 등을 정리해 무제한 누적을 막는다.
- 향후 성장에 따라 투사체 수치와 능력이 달라질 수 있지만 현재 기본값에 임의의 성장 기능을 추가하지 않는다.

## 충돌·피격·사망·소환물

- 플레이어의 충돌 영역과 피격 영역은 동일하게 적용한다.
- 플레이어와 적은 서로 몸체를 통과할 수 없다. 이는 비관통 투사체 규칙과 별개의 이동 충돌 규칙이다.
- 플레이어의 피격 간격은 **3초**이며 플레이어의 공격 간격 및 적의 공격 간격과 별도로 관리한다.
- 플레이어가 사망하면 게임을 종료하고 소환물도 모두 사망 처리한다.
- 소환물별 체력, 공격 가능 상태와 개별 사망 처리의 세부 설계는 보류한다.
- 적이 플레이어와 소환물 중 누구를 추적하는지는 적 지침의 대상 선택 규칙을 따른다.

## 경험치와 레벨

세부 규칙·필요량 공식·초기값은 [경험치 설계](../Experience.md)에서 관리한다.

- 적이 사망한 자리에 생긴 경험치 구슬이 획득 반경 안에 들어오면 플레이어에게 끌려오고, 플레이어 몸체에 닿으면 경험치가 누적된다.
- 경험치는 플레이어에게만 누적된다. 소환물은 경험치를 가지지 않는다.
- 획득 반경은 향후 성장할 수 있는 플레이어 능력치로 관리하되, 현재는 초기값으로 고정한다.
- 레벨 1에서 시작하며 상한은 없다. 필요량을 넘은 경험치는 이월하고, 한 번에 여러 레벨이 오를 수 있다.
- 레벨 n→n+1 필요량은 5에서 시작하는 연속형이며 증가량은 출발 레벨 1~9에서 5, 10~19에서 10, 20~29에서 20이고 이후 10레벨마다 두 배가 된다.
- 게임 종료 후에는 경험치를 획득하지 않는다.
- 레벨업 보상은 [레벨업 보상 설계](../LevelUpReward.md)에서 관리한다. 보상 설계가 확정·구현되기 전까지 능력치·투사체·공격 간격 등 기존 고정값을 바꾸지 않는다.

## 레벨업 보상

보상 목록·효과량·최대 중첩과 선택지 구성 규칙은 [레벨업 보상 설계](../LevelUpReward.md)에서 관리한다. 보류 항목은 임의로 구현하지 않는다.

- 레벨이 오르면 게임이 일시정지되고, 보상 선택지(기본 3개, 최대 5개) 중 하나를 반드시 골라 플레이어 능력을 강화한다.
- 보상은 공격력·공격 속도·최대 체력·이동속도·투사체 속도·획득 반경·선택지 수를 기본값 기준 고정 증가량만큼 올리거나 체력을 회복한다.
- 피격 간격 3초, 투사체 1개·비유도·비관통 규칙은 보상으로 바뀌지 않는다.
- 보상으로 바뀐 능력치는 이번 게임에서만 유지되며, 다시 시작하면 '현재 고정할 초기 능력치'로 돌아간다.
- 위 초기 능력치 표는 게임 시작 시의 값이다. 게임 중에는 확정된 보상으로만 값이 바뀌며, 그 밖의 성장·강화 규칙을 임의로 추가하지 않는다.
- 게임 종료 후에는 레벨업과 보상 선택이 일어나지 않으며, 레벨업과 사망이 같은 프레임에 일어나면 게임 종료가 우선한다.
- 보상 효과와 중첩 계산은 자동 테스트로 검증한다.
- 경험치 누적과 레벨 계산은 자동 테스트로 검증한다.

## 현재 유지할 이동과 표시

- 3000×3000 월드의 중앙에서 시작하며 화면 크기는 1280×720이다.
- WASD·방향키로 초당 250픽셀 이동한다. 대각선 속도는 직선 속도와 같고 키를 놓으면 멈춘다.
- 울타리와 장애물을 통과하지 않으며 장애물에 닿으면 막히지 않은 방향으로 이동할 수 있다.
- 비석과 마른 나무의 위쪽 통과 영역 및 발밑 기준 그리기 순서(`getFootDepth`)를 유지한다. 뒤에 있는 플레이어는 장애물에 가려진다.
- 카메라는 플레이어를 추적하되 월드 바깥을 보여주지 않는다.
- 현재 플레이어 그림은 40×40픽셀 사각형이며 이 크기를 설계값 1의 기준으로 유지한다.

## 구현 시 초기 설정 후 조정할 항목

사용자가 초기 설정을 위임한 항목이다. 게임에 맞는 시작 값과 선택 이유를 기록하고 플레이 테스트로 개선한다.

- **투사체 수치:** 속도·크기·수명 및 발사 위치. 발사 수 1개, 비유도·비관통, 장애물 통과와 화면 밖 피해 규칙은 유지한다.
- **공격 대기와 대상 검사:** 대상이 없을 때의 타이머 관리, 화면 진입 감지와 대상 갱신 방식. 불필요한 매 프레임 전체 적 정렬·탐색이나 투사체 생성을 피한다.
- **투사체 정리:** 수명과 월드 경계 등 정리 조건. 카메라의 화면 경계 자체를 삭제 기준으로 사용하지 않는다.
- **경험치 획득:** 획득 반경(초기 100px)과 끌어당김 속도(초기 초당 450px). 끌려오는 구슬은 장애물을 통과한다.

## 추후 확인 및 보류 항목

아래 항목은 미확정이며 사용자 검토 후 규칙으로 옮긴다.

- **거리 동률 처리:** 화면 안에 같은 거리의 적이 여러 명일 때의 우선순위.
- **소환물 설계(보류):** 종류와 능력치, 공격 가능 상태 및 개별 사망 처리. 플레이어 사망 시 전체 사망 규칙은 유지한다.
- **직업별 차이(추후):** 직업 종류와 스탯·능력의 차이. 현재 고정값에 추가 성장·강화 규칙을 임의로 붙이지 않는다.
- **레벨업 보상 보류 항목:** 투사체 수·관통 보상(위 '한 번에 1개·비관통' 규칙 변경 수반), 다시 뽑기·건너뛰기, 직업별 보상 목록. [레벨업 보상 설계](../LevelUpReward.md)의 보류 항목을 따른다.

## 플레이어 테스트 및 구현 시 확인

공통 시간·충돌·투사체 검사는 [전투 테스트 지침](../Combat/AGENTS.md)을 함께 따른다.

- 정상 활성 상태에서 20ms×50회와 100ms×10회가 모두 게임 시간 1초와 250픽셀 이동으로 이어지는지 검사한다. 불규칙한 프레임 간격에서도 같은 총 시간을 비교한다.
- 직선·대각선 이동 속도, 0.5초 공격 간격과 3초 피격 간격을 서로 다른 프레임 간격에서 검사한다.

- 체력 100·공격력 10·40×40픽셀 크기·0.5초 공격 간격이 올바르게 적용되는지 확인한다.
- 카메라가 월드 중앙과 경계에 있을 때 모두 중심이 화면 안에 있는 최근접 적을 선택하고, 화면 밖으로 나간 대상에 대한 새 공격을 중지하는지 확인한다.
- 이동 중 자동 공격, 대상 진입·교체·부재 시 처리와 3초 피격 간격이 서로 영향을 주지 않는지 확인한다.
- 투사체가 1개씩 비유도로 발사되고 장애물은 통과하지만 처음 맞힌 적에게만 피해를 주는지 확인한다.
- 화면 밖 투사체도 적에게 피해를 주며 적중·수명 종료 등 정리 조건에 따라 누적 없이 제거되는지 확인한다.
- 플레이어 사망 시 게임 종료와 소환물 전체 사망이 적용되는지 확인한다.
- 경험치 누적, 레벨업 필요량의 경계와 구간 경계, 연속 레벨업과 초과분 이월, 게임 종료 후 획득 차단을 확인한다.
- 획득 반경 경계와 끌어당김 이동이 프레임 간격과 무관하게 같은 결과를 내는지 확인한다.
- 레벨업 보상 적용 후 바뀐 능력치로 이동·공격·피격·구슬 획득이 올바르게 동작하는지 확인한다.
- 기존 이동·장애물 충돌·앞뒤 가림·카메라 추적이 유지되는지 확인한다.
