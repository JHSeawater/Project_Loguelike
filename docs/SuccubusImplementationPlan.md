# 구현 계획: 플레이어블 서큐버스

**규모: 대.** 네 번째 직업 등록뿐 아니라 살아 있는 적의 편 전환, 원거리 공격·회복·충돌의 진영 구분, 유혹 해제와 아군 정리가 기존 전투 전반에 연결된다.

현재 코드와 미커밋 변경을 포함한 작업 트리를 기준으로 작성했다. 게임 코드 구현은 시작하지 않았다.

## 목표와 확정 사항

서큐버스를 캐릭터 선택 화면에서 골라 한 판을 진행할 수 있게 한다. 기존 세 직업의 능력과 전투 규칙을 유지한다.

사용자가 확정한 내용은 [직업 지침](Classes/AGENTS.md)의 보류 구상과 [결정 기록](Decisions.md)의 직업 항목에 반영했다.

- 추가할 직업은 서큐버스다.
- 기본 공격 대신 **화면 안 최근접 일반 적을 주기적으로 자동 유혹**한다.
- 유혹한 아군의 방어 강화는 **그 아군만 받는 피해를 비율로 감소**시키는 방식이다. 별도의 방어력 수치를 도입하지 않는다.
- **영구 아군은 최대 유혹 아군 수에 포함하지 않는다.** 최대 수는 임시 유혹 아군만 센다. 영구화하면 임시 유혹 자리가 즉시 비며, 영구 아군에 별도 수 제한을 추가하지 않는다.
- 유혹 만료 시 **가까운 유효 위치로 적을 복귀**시킨다. 확정된 수 집계·복귀 위치 조건의 원본은 [직업 지침의 서큐버스 구현 전 확정 사항](Classes/AGENTS.md#서큐버스-구현-전-확정-사항)에서 관리한다.
- 기존 보류 구상의 무한 특기 및 특수 특기 두 종류를 설계 출발점으로 사용한다.

## 요구사항

- [ ] R1. 네 번째 직업으로 선택·시작·종료·다시 시작할 수 있고 이전 판의 상태가 남지 않는다.
- [ ] R2. 서큐버스는 일반 투사체나 근접 베기를 하지 않고, 조건에 맞는 일반 적을 자동 유혹한다. 보스와 이미 아군인 개체는 유혹하지 않는다.
- [ ] R3. 유혹한 적은 원래 종류의 근접·원거리·회복 특성을 유지하며 플레이어 편에서 행동한다. 서로 적대하는 진영만 공격한다.
- [ ] R4. 최대 임시 유혹 아군 수·공격력·체력·받는 피해를 개선하는 전용 무한 특기가 동작한다. 피해 감소는 유혹 아군에게만 적용한다. 직업 특수 특기는 두 개이며 각각 한 번만 획득한다.
- [ ] R5. 영구 아군화와 희생 회복이 유혹 만료·사망·일시정지·보스 보상과 일관되게 동작한다. 영구 아군은 최대 유혹 아군 수에서 제외하고 영구화 즉시 임시 자리를 반환한다.
- [ ] R6. 유혹 자체나 목록 이동으로 처치·경험치가 생기지 않고, 실제 적 처치 보상은 중복 없이 지급된다.
- [ ] R7. 선택 카드·임시 유혹 아군 현재/최대 수·별도의 영구 아군 수·시각적 진영 구분이 실제 게임 상태를 반영하고 모든 카드가 1280×720 안에 들어간다.
- [ ] R8. 워록·데스 나이트·네크로맨서, 적 9종, 보스·성장·충돌·시간 처리의 기존 회귀 검사를 유지한다.

## 아직 확정되지 않은 설계와 제안

아래 수치와 미확정 행동은 구현을 검토할 수 있도록 만든 **제안**이며 현재 구현값이 아니다. 위 확정 사항과 직업 지침을 참조하는 항목은 확정 규칙을 따른다. 유혹 방식·피해 감소 방식·영구 아군의 수 제한 제외·가까운 유효 위치 복귀는 결정됐으며, 나머지 제안을 바꾸면 해당 단계와 테스트 기대값을 함께 조정한다.

### 보상 제안

명칭도 제안이다. 효과량은 설정에서 관리하고 카드 문구는 같은 설정으로 만든다.

| 구분 | 제안 이름 | 효과 / 등급 |
| --- | --- | --- |
| 무한 특기 | 매혹의 군세 | 최대 임시 유혹 아군 +1 / 언커먼 |
| 무한 특기 | 지배 강화 | 유혹 아군 공격력·최대 체력 +20%p/중첩 / 언커먼 |
| 무한 특기 | 매혹의 가호 | 유혹 아군이 받는 피해 배율을 `100 / (100 + 20 × 중첩)`로 계산 / 레어 |
| 특수 특기 | 영원한 매혹 | 살아 있는 아군의 연속 유혹 시간이 10초에 도달하면 영구 아군화 / 에픽·1회. 임시 유혹 15초보다 짧아 획득 후에는 최대 임시 수가 동시 보유 상한이 아니라 영구 아군 증가 속도 제한으로 작동한다(유혹 간격 3초면 분당 최대 약 20명, 공격 속도 5회 1.5초면 약 40명). 이 관계는 확인 항목 C4 |
| 특수 특기 | 생명 공물 | 서큐버스 체력이 최대의 30% 이하이고 살아 있으면 아군 1명을 자동 희생해 최대 체력의 30% 회복. 재사용 8초 / 에픽·1회 |

- 피해 감소는 중첩 제한 없이 효과가 이어지되 양수 피해는 최종 반올림 후 최소 1로 제한한다. 플레이어와 다른 직업 소환물에는 적용하지 않는다.
- 희생은 임시 아군을 우선하고, 그 안에서 체력 비율이 가장 낮은 개체를 고른다. 임시 아군이 없으면 영구 아군 중 고른다. 동률이면 생성 ID가 작은 개체다. 아군이 없으면 발동·재사용 시간 소비가 없다.
- 치명타로 이미 사망한 플레이어를 희생으로 살리지 않는다. 특기 획득 당시 이미 체력이 낮아도 다음 활성 업데이트에서 발동할 수 있게 한다.
- 영구 아군의 수 제한 제외는 [직업 지침의 확정 사항](Classes/AGENTS.md#서큐버스-구현-전-확정-사항)을 따른다. 영구는 이번 판에서 유혹이 풀리지 않는다는 뜻이며 사망과 판 종료는 적용한다. 공격력·체력 강화와 피해 감소는 임시·영구 유혹 아군 모두에게 적용한다.
- 영원한 매혹을 얻기 전부터 유혹한 아군도 연속 유혹 시간을 사용한다. 획득 후 다음 활성 업데이트에 기준을 만족하면 전환한다.

### 공통·보스 보상과의 연결 제안

- 공통 공격력 강화와 보스 보상 공격력 배율은 유혹 아군의 실제 피해에 적용한다. 예: `유혹 당시 적 공격력 × (서큐버스 유효 공격력 / 시작 공격력) × 지배 강화 배율`을 한 번 반올림한다.
- 위 식에서 `유혹 당시 적 공격력`(그때의 가호 포함)만 유혹할 때 고정하고, `서큐버스 유효 공격력`과 `지배 강화 배율`은 공격할 때마다 현재 값으로 계산한다. 좀비의 '시체 강화'가 이미 있는 좀비의 공격력에 바로 적용되는 방식과 맞춘 제안이며 확인 항목 C5다.
- 공격 속도 강화는 유혹 간격을 줄인다. 유혹 아군 자체의 원래 공격 간격은 유지한다.
- 투사체 속도 강화는 후보에서 제외한다. 유혹한 원거리 아군은 원래 종류의 투사체 속도를 사용한다.
- 체력·이동·획득 반경·경험치·선택지·회복 보상과 나머지 보스 보상은 기존 의미를 유지한다.
- 지배 강화의 체력 변화와 유혹 시작·해제는 현재 체력 비율을 보존한다. 원본 기준값을 보관해 반복 전환과 반올림으로 체력을 공짜로 회복하지 않게 한다.
- 사제의 회복량은 원래 종류의 값을 사용한다. 공격력 강화로 회복량까지 증가시키지 않는다.

### 누락되기 쉬운 규칙 제안

| 상황 | 제안 동작 |
| --- | --- |
| 임시 유혹 만료 | 같은 개체 ID·종류로, [직업 지침의 복귀 위치 조건](Classes/AGENTS.md#서큐버스-구현-전-확정-사항)을 만족하는 가까운 위치에 적으로 복귀. 체력 비율 보존, 기존 추적 대상·경로 무효화. 공격 간격은 초기화해 즉시 추가 공격하지 않음 |
| 가까운 유효 위치 탐색 | 제안(C3): 현재 위치가 유효하면 유지. 무효면 현재 몸체 좌상단을 기준으로 반경 10px 간격의 동심 링을 반경 200px까지 차례로 검사하고, 각 링에서 오른쪽(0°)부터 화면 좌표의 시계 방향(+y가 아래)으로 22.5°씩 16방향을 검사해 처음 유효한 위치를 쓴다. 반경이 작은 후보가 먼저이고 같은 반경에서는 검사 순서가 동률을 정한다. 200px 안에서 찾지 못하면 아래 '찾을 수 없음'을 따른다 |
| 가까운 복귀 위치를 찾을 수 없음 | 제안: 유효 위치가 생길 때까지 임시 유혹과 임시 자리·적 생성 자리 예약을 유지하고 다음 활성 업데이트에서 재시도. 실패만으로 사망·처치·경험치·영구화를 발생시키지 않음. 영구화 조건이 별도로 성립하면 기존 영구화 우선순위 적용 |
| 사망 / 만료 / 영구화가 같은 경계에 도달 | 죽은 개체는 전환하지 않음. 살아 있고 영구화 조건을 만족하면 만료보다 영구화를 먼저 처리 |
| 편 전환 순간 | 적 목록과 유혹 아군 목록 중 한 곳에만 존재. 아군 대상 후보 목록과 주변 적의 낡은 대상 참조를 함께 갱신 |
| 이미 발사된 투사체 | 발사 당시 진영과 능력치를 유지. 발사자가 편을 바꿔도 투사체를 소급 전환하지 않음. 제안(C6): 투사체에 발사자 ID를 보관하고, 발사자가 편을 바꾼 뒤 전환 전에 쏜 자기 탄에는 맞지 않음. 다른 대상은 발사 당시 진영으로 판정 |
| 단계 안 처리 순서 | 제안(C2): `step()`에서 이동 → 생성 → `updateEnemies` → `resolveHazards` → (게임 종료면 중단) → 유혹 아군 행동(현재 `updateZombies` 위치) → 유혹 수명 처리 [죽은 유혹 아군 정리·자리 반환 → 영구화 → 만료 복귀 → 희생] → 서큐버스 유혹 시도(현재 플레이어 공격 위치) → `updateProjectiles` → 죽은 아군 정리 → 구슬 순서. 목록 이동은 적·아군 목록 순회가 끝난 뒤에만 하고, 같은 단계에서 투사체로 생긴 피해는 다음 단계의 수명 처리에 반영 |
| 유혹 아군의 피격 간격·배리어 | 제안(C1): [소환물 공통 규칙](Player/AGENTS.md)처럼 맞은 뒤 0.3초 동안 다시 피해를 받지 않고, 성스러운 방벽의 배리어는 적용하지 않음. 현재 `dealDamage`는 `allies`에 등록된 개체에 피격 간격을 자동 적용하므로, 적용하지 않기로 하면 별도 분기가 필요. 적으로 복귀하면 적 규칙(피격 간격 없음)으로 돌아감 |
| 복귀한 개체의 재유혹 | 제안(C7): 별도 대기 없이 다음 유혹 시점에 다시 대상이 될 수 있음. 재유혹은 새 유혹으로 보고 영원한 매혹의 연속 유혹 시간은 0부터 다시 셈 |
| 원거리 아군 | 종류별 원거리 행동·투사체 규격 유지. 워록 발사 수·유도·폭발 효과를 상속하지 않음 |
| 유혹한 사제 | 자신을 제외한 플레이어와 유혹 아군만 회복. 적 사제는 적만 회복 |
| 보스 방벽 / 범위 공격 | 유혹 아군은 적 방벽 보호 대상에서 제외하고 보스의 공격 대상에는 포함 |
| 유혹 아군의 행동 | 기존 좀비의 감지·복귀 범위 규칙을 출발점으로 사용하되, 근접·원거리·사제별 원래 공격·정지 사거리는 유지. 대상이 없으면 플레이어 근처로 복귀 |
| 플레이어와 아군의 충돌 | 소환물 공통 규칙처럼 서로 통과. 장애물·적·다른 아군과는 원래 몸체 전체로 충돌 |
| 적 생성 상한 | 임시 유혹한 일반 적은 복귀할 생성 자리를 예약해 상한에 포함. 영구화하면 임시 유혹 자리와 적 생성 자리 예약을 모두 반환하고 영구 아군 수만 증가. 유혹 만료 때에는 유효 위치로 실제 복귀한 뒤 예약을 해제해 적 수 상한을 초과시키지 않음 |
| 유혹 성공·해제·아군 전사·희생 | 처치 수와 경험치 없음. 유혹 아군이 적을 처치하면 기존 처치·구슬 지급. 적으로 돌아온 뒤 죽으면 정상 적 사망 보상 |
| 적의 가호·시간 강화 | 생성 당시 최대 체력을 원본으로 보관. 유혹 당시 공격력·이동속도에 적용된 가호는 아군 기준값으로 저장하고 이후 적 전용 가호를 중복 적용하지 않음. 적 복귀 후에는 현재 적 가호 규칙 적용 |
| 보상 선택 / 게임 종료 / 재시작 | 유혹·영구화·희생 시간과 AI는 게임 시간으로 정지. 판 종료 시 아군 정리, 재시작 시 새 상태 |

## 구현 단계

각 단계는 기존 게임과 빌드가 동작하는 상태로 마친다. 서큐버스 카드는 전투와 표시가 준비될 때까지 노출하지 않는다.

1. **설계 기준 확정 및 직업 데이터 등록**
   - 제안 표와 [구현 전 사용자 확인 항목](#구현-전-사용자-확인-항목) C1~C7을 항목별로 **사용자에게 확인**받고, 확인된 내용만 관련 지침에 기록한다. 확인되지 않은 항목에 기대값이 걸린 단계는 2단계 이후로 진행하지 않는다.
   - ID·공격 종류·설정·보상 ID·초기 중첩·직업별 제외 목록을 함께 추가한다. `charm`이 기존 투사체 분기로 떨어지지 않게 한다.
   - `CharacterId`가 확장되는 같은 단계에서 `src/main.ts`와 `src/menu-scenes.ts`의 모든 `SPRITE_ART` 조회에 이미지 없는 직업을 안전하게 처리하는 최소 분기를 추가한다. 카드 비노출만으로 타입 문제를 회피하지 않는다. 코드 도형 표시의 완성은 6단계에서 진행한다.
   - 완료 조건: 새 직업 생성·능력치·후보 테스트와 기존 보상 테스트 통과. 화면 안에 적이 있어도 서큐버스가 플레이어 탄을 만들지 않고 휘두르기 기록·효과도 없음을 테스트로 확인. 스프라이트 조회를 포함한 전체 TypeScript 검사·빌드 통과, 기존 세 직업 유지.
2. **유혹 대상 선택과 편 전환 수명 구현**
   - 같은 적 객체를 전용 유혹 아군 목록으로 옮기고 `allies`에 등록한다. 원래 종류·ID·기준 능력치와 유혹 시작·만료 시각을 보관한다.
   - 일반 적 최근접 선택·간격·최대 임시 수·임시 복귀·생성 자리 예약을 구현한다. 임시와 영구의 수 집계는 분리한다. 전환 시 낡은 대상·경로를 무효화한다.
   - 만료 시 현재 위치의 유효성을 먼저 확인하고, 겹침이 있으면 확인된 탐색 규칙(C3)으로 가까운 유효 위치를 찾는다. 복귀 위치를 찾지 못한 경우의 제안 동작도 함께 검증한다. 유혹 시작으로 적 간 겹침 허용이 바뀌는 경우도 확인한다.
   - 유혹 수명 처리와 유혹 시도는 확인된 단계 안 처리 순서(C2)에 한 번씩 둔다. `for (const enemy of this.enemies)` 같은 순회 도중에는 목록을 옮기지 않는다.
   - 유혹 아군의 피격 간격·배리어는 확인된 규칙(C1)을 따르고, 재유혹은 C7을 따른다.
   - 완료 조건: 보스 제외·화면 경계·최대 임시 수·정확한 만료·유효 위치 복귀·복귀 실패 시 예약 보존·목록 중복 없음·전환만으로 보상 없음이 테스트로 확인됨. 복귀 좌표는 탐색 규칙으로 계산한 기대 좌표(현재 위치 유지, 첫 링의 특정 방향, 더 먼 링, 200px 안 실패)와 일치함을 검사.
3. **유혹 아군의 전투와 진영 연동**
   - 기존 적 행동에서 필요한 부분만 좁게 재사용해 근접·원거리·사제 아군 행동을 연결한다.
   - 투사체에 최소한의 발사 출처(적 종류)와 발사자 ID를 보관해 플레이어 탄과 유혹 아군 탄의 규격·특기 적용을 분리한다. 전환 전 자기 탄 처리는 C6을 따른다.
   - 적 추적·접촉·투사체·회복·보스 방벽·보스 범위 공격에 진영을 반영한다. 아군 이동은 기존 소환물 충돌 규칙을 따른다.
   - 완료 조건: 일반 적 8종의 유혹 후 행동과 보스 연동 테스트, 기존 투사체·보스·네크로맨서 테스트 통과.
4. **무한 특기와 공통 강화 연결**
   - 최대 임시 수·공격/체력 강화·받는 피해 감소를 실제 아군에게 적용한다. 체력 비율과 원본 기준을 보존한다.
   - 서큐버스 공격력과 공격 속도 보상이 실제 아군 피해·유혹 간격에 반영되게 한다. 피해 계산 시점은 C5를 따르며, 유혹 후에 얻은 공격력 강화가 이미 있는 아군의 다음 공격부터 반영되는지 검사한다.
   - 피해 감소 특기를 활성화한 상태에서 임시·영구 유혹 아군과 플레이어·일반 적·다른 직업 소환물을 비교해 적용 범위를 확인한다. 유혹 해제 후 효과가 남지 않는지도 검사한다.
   - 완료 조건: 0·1·다중·큰 중첩, 최소 피해·반올림·반복 유혹/해제, 강화 전후 순서 및 대상별 피해 비교에서 기대 결과 확인.
5. **특수 특기 두 종류 구현**
   - 영구화의 시간 경계와 획득 이전부터 있던 아군 처리를 구현한다.
   - 영구화하면 최대 임시 수의 집계에서 즉시 제외하고 임시 유혹 자리와 적 생성 자리 예약을 반환한다. 영구 아군이 누적되어도 임시 수가 상한보다 작으면 새 유혹이 가능하게 한다.
   - 희생 회복의 발동·개체 선택·회복 상한·재사용·사망 우선순위를 구현한다.
   - 완료 조건: 각 특기의 1회 획득·보스 획득·정확한 경계·영구 수 제외·자리 즉시 반환·영구 아군 누적 후 재유혹·아군 부재·연속 피격·치명타·일시정지 테스트 통과.
6. **게임 표시 연결**
   - 유혹한 적은 기존 종류별 스프라이트를 재사용하고 코드로 그린 분홍 표시와 영구 여부로 적과 구분한다. 개체 ID를 유지해 편 전환 시 중복 표시를 막는다.
   - 현재 `enemyViews`는 `battle.enemies`에 없는 ID의 표시를 지우므로, 편 전환 때 기존 표시를 지우지 않고 유혹 아군 표시 목록으로 옮겨(복귀 때는 반대로) 재생 상태를 이어 쓴다.
   - `shotArt`는 `team === 'ally'`여도 적 종류 발사 출처가 있으면 그 종류의 외형을 우선한다. 유혹한 궁사·마법사·석궁병의 탄이 원래 외형으로 보이게 하고, `tests/sprite-application.test.mjs`의 `shotArt` 기대값에 이 경우를 추가한다(기존 플레이어 탄 기대값은 유지).
   - HUD에 임시 유혹 아군 현재/최대 수와 영구 아군 수를 나눠 표시하고 사망·해제·희생 시 표시를 정리한다. 영구화 직후 집계와 표시가 함께 바뀌게 한다. 새 게임에서 이전 개체와 상태를 초기화한다.
   - 서큐버스 전용 원본·프로필은 현재 없다. 기본안은 외부 이미지 추가 없이 코드 도형으로 임시 표시하며, 기존 직업 스프라이트는 유지한다.
   - 완료 조건: 전투 상태와 표시가 일치하며 일시정지·종료 중 프레임·방향이 멈추고 재시작 시 잔상이 없음.
7. **선택 화면에서 플레이 가능하게 연결**
   - `PLAYABLE`에 서큐버스를 추가하고 `PLANNED`에서 해당 잠금 카드를 제거한다. `describe`의 패시브 기본 분기를 고쳐 데스 나이트 설명이 표시되지 않게 한다. 공격 문구도 `shot`이 아니면 휘두르기 문구로 가므로 `charm` 분기를 추가해 "주변 0px 안의 적 전부 베기"가 표시되지 않게 한다.
   - 네 장을 가로 배치하는 초기안은 카드 288×420, 간격 16, 위쪽 96px이다(전체 너비 1200px, 아래 끝 516px). 잠긴 두 카드는 230×64로 위쪽 532px에 두어 아래 끝 596px이 되고, y=640 중심의 안내 문구와 약 34px 떨어진다. 문구가 카드 안에서 넘치면 실제 화면에서 글자 크기·줄 간격을 조정하고 바뀐 값을 UI 지침에 기록한다.
   - 숫자 4·클릭·기존 좌우 순환·Enter와 입력 지연을 확인한다. 카드 수치는 설정을 표시한다.
   - 완료 조건: 네 직업 각각 선택 가능, 카드·문구 겹침 없음, 기존 입력 흐름 유지.
8. **전체 회귀·플레이 확인·문서 마무리**
   - 전체 자동 테스트와 TypeScript/Vite 빌드를 실행한다. 최대 적 수 근처에서 임시·영구 유혹 아군이 있는 전투 처리 시간을 측정한다. 장기 플레이로 영구 아군이 누적되는 조건도 포함해 아군 수·투사체 수·측정 시간을 기록하고 이전 기록과 조건을 구분해 보고한다. 성능 검증을 이유로 임의의 영구 아군 수 제한을 추가하지 않는다.
   - 측정 시나리오: 실제 맵, 10:00 이후(최대 적 90), 공격 속도 강화 5회, 영원한 매혹 보유, 영구 아군 50·100·200명. 렌더링을 제외한 한 업데이트의 평균·상위 5%·최대 처리 시간을 [전투 지침의 측정 기록](Combat/AGENTS.md)(적 89마리 평균 0.69ms)과 같은 방식으로 잰다.
   - 경로 탐색 예산(단계당 4회)은 적이 먼저 쓰고 아군이 남은 양을 쓰는 현재 순서를 유지하되, 아군이 경로 없이 대기한 시간 비율도 함께 기록한다.
   - 한 업데이트가 한 단계 길이(50ms)의 일정 비율을 넘거나 아군 경로 대기가 두드러지면, 상한이나 예산 배분을 임의로 바꾸지 않고 측정 결과와 선택지를 사용자에게 보고해 결정을 받는다.
   - 브라우저에서 새 직업의 유혹·전투·특기·종료·다시 시작과 기존 세 직업을 확인한다. 확정 규칙·검사 항목을 분야별 문서에 반영한다.
   - 완료 조건: R1~R8의 자동·수동 확인 결과와 미확인 항목이 기록됨. 관련 없는 변경과 커밋 없음.
