# 설계 결정 기록

분야별 지침의 규칙과 수치가 정해진 경위다. 현재 지켜야 할 규칙은 각 분야의 AGENTS.md를 따르며, 이 기록과 다르면 AGENTS.md가 우선한다. 새 결정은 해당 분야 섹션 끝에 다음 번호로 추가하고, 이전 결정을 바꾸면 그 항목에 변경한 번호를 표시한다.

## 적·전투

관련 지침: [적](Enemy/AGENTS.md) · [전투](Combat/AGENTS.md)

| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 적 크기 | 기사 120×80, 성기사 80×120으로 확정 (#11에서 변경) |
| 2 | 사거리·시간 단위 | 사거리 1=40픽셀, 공격 간격은 초 단위. 수치는 추후 조정 |
| 3 | 근접 사거리 | 기사 사거리를 1(40px)로 조정. 모든 근접 적은 실제 접촉 시에만 피해 |
| 4 | 이동속도·생성 밀도 | 현재 속도와 1.8초 생성 주기·최대 30개를 유지하고 개발하며 조정 (생성 밀도는 #8에서 변경) |
| 5 | 동률과 도달 불가 | 적은 거리 동률 시 현재 대상을 유지하고, 도달 불가 시 대기 후 재탐색 |
| 6 | 프레임 진행 | 50ms 단위 분할 진행과 한 프레임 250ms 상한. 이전의 50ms 제한은 20FPS 미만에서 게임 시간을 버려 지침과 맞지 않았음 |
| 7 | 투사체 수명 경계 | 만료 시점에 정확히 닿는 적중은 피해 없음. 그 이전의 적중은 프레임 간격과 관계없이 유효 |
| 8 | 생성 증가와 신규 적 | 게임 시간 기준 단계적 생성 증가, 광신도 무리·포위 웨이브, 신규 적 광신도·석궁병·사제 적용. 수치는 적 지침에서 조정. 보스는 보류 |
| 9 | 초반 생성 주기 | 0:00 단계 1.8초 → 1.0초, 1:00 단계 1.5초 → 0.9초. 워록이 가만히 있을 때 첫 1분간 화면 안 적이 평균 0.9마리뿐이라 초반이 루즈했고, 조정 후 약 6마리(실제 맵, 난수 5가지 평균) |
| 10 | 등장 간격·포위 웨이브 | 새 적 등장 간격이 길다는 피드백에 따라 1분 간격으로 앞당김(석궁병 4:00 → 3:00, 사제 6:00 → 4:00). 생성 주기·최대 적 수는 유지. 포위 웨이브는 3:00·7:00 두 번에서 2:30부터 2분 30초마다 반복으로 변경 |
| 11 | 적 크기·이동속도·체력 | 적이 장애물에 잘 낀다는 피드백에 따라 크기를 px 기준으로 줄임(기사 80×60, 성기사 60×80, 궁사·사제 30×40, 광신도 25×30). 이동속도와 일부 체력도 함께 조정 |
| 12 | 적끼리 겹침 | 적이 무리 지어 잘 막힌다는 피드백에 따라, 장애물처럼 몸체 위쪽 25%를 다른 적이 겹쳐 지나갈 수 있게 함. 플레이어·장애물과의 충돌과 피격 판정은 몸체 전체 유지 |
| 13 | 멈춘 원거리 적 통과 | 사거리에서 멈춘 원거리 적 줄 뒤에 근접 적이 막힌다는 문제에 따라, 사거리 안에서 멈춘 원거리 적·사제는 다른 적의 이동을 막지 않게 함 |

## 경험치

관련 지침: [성장](Progression/AGENTS.md)

| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 획득 방식 | 처치 위치에 구슬을 떨어뜨리고 플레이어가 접근해 획득 |
| 2 | 끌어당김 | 획득 반경 안의 구슬이 끌려옴. 획득 반경은 추후 성장 가능 |
| 3 | 구슬 유지 | 사라지지 않음. 최대 수 초과 시 가장 오래된 구슬에 값을 합침 |
| 4 | 레벨업 필요량 | 구간별로 증가량이 커지는 연속형(5씩 → 10씩 → 20씩). 30레벨 이후 10레벨마다 증가량 2배 |
| 5 | 초과 경험치 | 이월하고 연속 레벨업 허용 |
| 6 | 레벨 상한 | 없음 |
| 7 | 레벨업 보상 | 경험치 단계에서는 표시까지만 구현하고 보상은 별도 설계 (아래 '레벨업 보상'에서 설계) |
| 8 | 처치 주체 | 처치 주체와 관계없이 적 사망 시 경험치 발생 |
| 9 | 게임 종료 화면 | 최종 레벨 표시 |

## 레벨업 보상

관련 지침: [성장](Progression/AGENTS.md) · [UI](ui/AGENTS.md)

| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 선택 중 진행 | 일시정지 |
| 2 | 선택지 개수 | 기본 3개. 선택지 추가 보상으로 최대 5개 |
| 3 | 보상 종류 | 권장 7종에 선택지 추가(+1) 보상을 더한 8종 |
| 4 | 투사체 수·관통 보상 | 나중에 결정(보류). 투사체 수는 #12에서 결정 |
| 5 | 증가 방식 | 기본값 기준 고정 증가량. 플레이 후 조정 |
| 6 | 최대 중첩 | 공격력·최대 체력 10회로 조정, 나머지는 권장값 |
| 7 | 선택지 구성 | 미도달 보상 중 중복 없이 균등 무작위, 체력 회복은 항상 후보 |
| 8 | 연속 레벨업 | 오른 레벨 수만큼 순서대로 선택, 매번 새로 구성 |
| 9 | 다시 뽑기·건너뛰기 | 보류. 현재는 반드시 하나 선택 |
| 10 | 직업별 보상 | 직업 설계 시까지 보류. 현재는 공통 목록 (#13에서 변경) |
| 11 | 보유 보상 표시 | HUD에는 표시하지 않고 선택창에 중첩 수 표시 |
| 12 | 투사체 수 | 공통 보상이 아닌 워록 무한 특기 '다중 시전'으로 증가. 관통은 계속 보류 |
| 13 | 직업별 보상 | 공통 보상과 직업 특기를 같은 선택지에 섞고, 직업 컨셉에 맞지 않는 공통 보상은 제외 |
| 14 | 특수 특기 확률 | 가중치 0.1(다른 후보 1), 1회 획득 |

## 직업

관련 지침: [직업](Classes/AGENTS.md) · [플레이어](Player/AGENTS.md)

| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 직업 컨셉 | 맵·적 분위기에 맞춘 악역 직업 6종 구상 |
| 2 | 구현 범위 | 워록과 데스 나이트를 먼저 구현하고, 나머지는 보류 구상으로 둠 |
| 3 | 기존 기본 캐릭터 | 워록으로 전환. 기본 능력치와 투사체 자동 공격은 그대로 유지 |
| 4 | 패시브 | 처음부터 적용 |
| 5 | 무한 특기 | 공통 보상 외에 그 직업만 중첩 제한 없이 얻는 특기 |
| 6 | 특수 특기 | 그 직업에서 매우 낮은 확률로 나오는 특기. 초기 가중치 0.1, 1회 획득 |
| 7 | 선택지 구성 | 공통 보상과 같은 선택지에 섞고, 직업 컨셉에 맞지 않는 공통 보상은 제외 |
| 8 | 초기 수치 | 적당한 값으로 시작해 플레이 테스트로 조정 |
