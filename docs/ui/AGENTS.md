# UI 개발 지침

[루트 개발 지침](../../AGENTS.md)과 함께 적용한다. 화면 흐름(타이틀·캐릭터 선택), 화면에 고정된 정보 표시(HUD)와 게임 종료 화면은 이 문서에서 관리한다. 표시할 수치의 규칙은 [플레이어 지침](../Player/AGENTS.md)과 [적 지침](../Enemy/AGENTS.md)을 따른다.

## 화면 흐름

타이틀 → 캐릭터 선택 → 게임 순서로 진행하고, 게임이 끝나면 캐릭터 선택으로 돌아간다. 장면은 `src/menu-scenes.ts`(타이틀·캐릭터 선택)와 `src/main.ts`(게임)에서 관리한다.

- **타이틀:** 게임 제목(가제 'Grave of the Fallen'), 시작 안내, 조작 안내를 표시한다. Enter·Space·클릭으로 캐릭터 선택으로 넘어간다.
- **캐릭터 선택:** 구현된 직업마다 번호·표시 색·이름·시작 능력치·공격 방식·패시브·특기 이름을 카드로 보여준다. 카드 내용은 직업·특기 데이터를 그대로 표시하며 UI에서 따로 수치를 정하지 않는다.
- 보류 구상 직업은 '준비 중'인 잠긴 카드로 이름만 보여주며 고를 수 없다.
- 클릭이나 숫자키로 바로 시작한다. ←→·A·D로 고른 뒤 Enter·Space로 시작할 수도 있으며, 마우스를 올린 카드도 선택된다. Esc는 타이틀로 돌아간다.
- **게임 종료 후:** Enter·클릭으로 캐릭터 선택으로 돌아간다. 새 게임은 이전 게임의 능력치·보상·적·표시 상태를 이어받지 않는다.
- 각 화면과 게임 종료 화면이 열린 직후 0.3초(실제 시간) 동안의 입력과, 키를 누르고 있어 반복되는 입력은 무시한다. 이전 화면에서 누르던 키가 다음 화면의 선택으로 이어지지 않게 한다.

## 현재 유지할 표시

- 화면 왼쪽 위 패널에 체력(현재/최대)·생존 시간·적 수·처치 수와 체력 바를 표시한다. 체력 바는 보상으로 늘어난 최대 체력 기준 비율이다.
- 체력·경험치 바는 전체 너비로 만들고 값의 비율만큼 줄여 표시한다. Phaser 도형의 표시 크기는 원래 크기에 대한 배율이므로 너비 0으로 만들면 늘어나지 않는다.
- 패널 하단에 적 9종(보스 포함)의 이름을 각 표시 색으로 한 줄에 5종씩 두 줄로 보여준다. 패널은 620×112px이다.
- 가호를 하나 이상 고르면 패널을 620×132px로 늘려 맨 아래 줄에 누적 가호를 붉은 글자로 표시한다(예: '가호: 적 체력 +20% · 공격력 +10%'). 고른 적 없는 가호는 표시하지 않는다.
- 사제의 회복은 실제로 회복한 적이 있을 때만 회복 반경을 분홍 원으로 0.15초(게임 시간) 동안 흐려지며 사라지게 표시한다.
- HUD는 카메라 이동과 무관하게 화면에 고정되며 월드 개체보다 위에 그린다.
- 게임 종료 시 화면 중앙에 직업·생존 시간·처치 수와 캐릭터 선택으로 돌아가는 안내를 표시한다.
- 사용자가 제공한 직업·좀비·적·투사체·경험치 구슬 이미지의 가공본은 로컬 PNG로 불러온다. 그 밖의 이미지와 글꼴은 별도 요청 없이 추가하지 않는다.

## 경험치 표시

경험치 규칙은 [성장 지침](../Progression/AGENTS.md)을 따른다.

- 현재 레벨과 다음 레벨까지의 경험치 진행도를 HUD에 표시한다.
- 게임 종료 화면에 생존 시간·처치 수와 함께 최종 레벨을 표시한다.
- 경험치 구슬은 외부 이미지 없이 코드로 그리며, 경험치 값에 따라 색을 구분한다.
- 표시 값은 게임 로직의 경험치·레벨 상태를 그대로 반영하며 UI에서 따로 계산하지 않는다.

## 레벨업 보상 선택창

보상 규칙은 [성장 지침](../Progression/AGENTS.md)을 따른다. 보류 항목은 임의로 구현하지 않는다.

- 레벨이 오르면 게임을 일시정지하고 화면 중앙에 보상 선택지(기본 3개, 최대 5개)를 보여주며 플레이어가 반드시 하나를 고르게 한다. 다시 뽑기·건너뛰기 버튼은 두지 않는다.
- 각 선택지에 보상 이름·1회 효과·현재/최대 중첩(예: 2/5)을 표시한다. HUD에는 보유 보상 목록을 표시하지 않는다.
- 카드 테두리는 보상 등급 색(커먼 회색, 언커먼 초록, 레어 파랑, 에픽 보라)으로 그린다. 등급은 [성장 지침](../Progression/AGENTS.md)의 '보상 등급'을 따른다.
- 중첩 칸에는 등급 이름 뒤에 중첩을 표시한다. 직업 무한 특기는 '직업 특기 · 중첩 n', 특수 특기는 '특수 특기 · 1회 획득', 최대 중첩이 없는 공통 보상은 '중첩 n · 제한 없음', 체력 회복은 '중첩 제한 없음'이다(예: '레어 · 직업 특기 · 중첩 2').
- 선택창이 열려 있는 동안 이동 키 입력은 플레이어 이동으로 이어지지 않는다.
- 선택창은 HUD와 월드 개체보다 위에 그리며 카메라 이동과 무관하게 화면에 고정한다.
- 선택지의 이름·효과·중첩 수는 게임 로직의 보상 상태를 그대로 표시하며 UI에서 따로 계산하지 않는다.
- 게임 종료 화면과 선택창이 동시에 열리지 않는다. 게임 종료가 우선한다.

## 직업 표시

직업 규칙은 [직업 지침](../Classes/AGENTS.md)을 따른다.

- 워록·데스 나이트·네크로맨서와 좀비는 사용자 제공 AI 이미지의 가공본으로 표시한다. 파일·프레임·레이어 규격과 재가공 절차는 [스프라이트 가이드의 적용 현황](../SpriteGenerationGuide.md#13-제공-원본-가공-및-적용-현황)을 따른다. 적 표시는 아래 '적 표시'를 따른다.
- 대기·걷기·시전·공격은 `src/sprite-animation.ts`의 공통 재생기로 게임 시간에 따라 진행하고 보상 선택·게임 종료 중에는 프레임과 방향을 함께 고정한다. 실제 몸체 변위가 없으면 걷지 않는다. 실제 공격 기록의 방향으로 공격하며 이동·피해·발사 시점을 애니메이션에 맞춰 지연하지 않는다. 다중 시전도 발사 한 번당 시전 한 번이다.
- 직업의 몸체와 손 주변 마법·검격은 별도 레이어지만 위치·프레임·피격 점멸은 함께 갱신한다. 좀비는 몸체만 사용하고 개체마다 독립된 재생 상태를 갖는다. 발밑 깊이를 사용하고 카메라는 판정 몸체 중심을 따라가며, 선택 화면은 직업별 정면 대기 첫 프레임을 재사용한다. 셀·앵커·재생 속도는 `sprite/profiles/` 설정을 가공기와 게임이 함께 읽는다.
- 데스 나이트의 휘두르기, 워록의 마력 폭발, 네크로맨서의 시체 폭발은 판정에 쓴 중심과 반경 그대로 반투명 원을 그려 0.15초(게임 시간) 동안 흐려지며 사라지게 한다. 휘두르기는 연보라, 마력 폭발은 주황색, 시체 폭발은 연두색이다.
- 네크로맨서의 좀비는 맞은 뒤 피격 간격 동안 플레이어처럼 깜빡이고 죽으면 표시도 제거한다. 그리기 순서는 발밑 기준이다. 네크로맨서로 플레이할 때 HUD 레벨 줄에 '좀비 현재/최대'를 표시한다.
- 효과 원은 투사체 위, HUD 아래(깊이 10001)에 그린다. 그 위(깊이 10002)에 사용자 제공 효과 그림(아래 '전투 효과 그림')을 겹친다.
- 워록의 마력 폭주가 지속되는 동안 HUD의 레벨 표시 오른쪽에 남은 시간을 표시한다.

## 적 표시

적 규칙은 [적 지침](../Enemy/AGENTS.md)을 따른다.

- 성기사단장을 포함한 적 9종은 사용자 제공 AI 이미지의 가공본으로 표시한다. 규격과 재가공은 [스프라이트 가이드의 적용 현황](../SpriteGenerationGuide.md#13-제공-원본-가공-및-적용-현황)을 따른다.
- 직업과 같은 공통 재생기로 대기·걷기·공격(마법사·사제는 시전)을 게임 시간에 따라 재생한다. 개체마다 독립된 재생 상태를 갖고, 실제 몸체 변위가 없으면 걷지 않으며, 실제 공격 기록의 방향으로 공격한다. 사제는 실제로 회복했을 때만 바라보던 방향 그대로 시전한다.
- 발밑 깊이를 사용하고 텍스처 크기로 판정을 바꾸지 않는다. 맞은 직후 0.1초(게임 시간) 동안 몸체 전체를 흰색으로 칠해 점멸하고, 죽으면 표시를 제거한다.
- 적의 PNG·재생과 근접·원거리·회복·보스 기술 기록은 `tests/sprite-application.test.mjs`에서 검사한다. 화면에서는 9종의 걷기·공격(시전), 피격 점멸, 기사단 소집을 확인한다.

## 전투 효과 그림

- 휘두르기·마력 폭발·시체 폭발·사제 회복은 기존 범위 원을 그대로 두고, 같은 중심에 효과 그림을 겹친다. 그림 폭이 판정 지름이 되게 균일 확대하므로 휘두르기 반경이 커지면 그림도 커진다. 사제 회복은 바닥 원이 사제 중심에 놓이는 빛기둥이라 위쪽으로 길게 솟는다.
- 단발 효과는 수명(범위 효과 0.15초, 보스 타격·좀비 부활 0.3초) 동안 모든 프레임을 고르게 한 번 재생하고 일시정지 중에는 멈춘다. 그림은 판정·피해 시각을 바꾸지 않는다.
- 좀비가 일어나면 좀비 발밑 중앙에 흙더미와 청록 혼불 그림을 원래 크기로 0.3초 동안 재생한다.
- 효과 표시 시각·크기·재생은 `tests/sprite-application.test.mjs`, 효과 시트 가공은 `tests/sprite-pipeline.test.mjs`에서 검사한다.

## 투사체·구슬 표시

- 투사체는 사용자 제공 이미지의 가공본으로 그린다. 기준점(발광탄의 핵, 화살·볼트의 회전축)을 판정 몸체의 중심에 두고 진행 방향으로 회전한다. 그림의 길이·회전으로 판정을 바꾸지 않는다.
- 플레이어 마탄은 직업 전용 마탄을 우선하고, 전용 이미지가 없는 직업은 공용 마탄(`ally_magic_bolt`)을 쓴다. 현재 워록은 전용 마탄(`warlock_bolt`), 네크로맨서는 공용 마탄을 쓴다. 전용 이미지가 생기면 `src/sprite-animation.ts`의 직업별 마탄 표에 추가한다.
- 적 투사체는 쏜 병종에 따라 궁사는 화살, 마법사는 보라 구체, 석궁병은 볼트로 그린다. 외형이 정해지지 않은 투사체는 기존처럼 판정 크기의 병종 색 사각형으로 그린다.
- 경험치 구슬은 값 구간마다 색이 다른 마름모 결정으로 그리고 회전하지 않는다. 구간은 [성장 지침](../Progression/AGENTS.md)을 따르며, 합쳐져 값이 바뀌면 바로 색을 바꾼다.
- 발광탄·구체는 12fps, 구슬은 8fps로 게임 시간에 따라 반복하고 일시정지 중에는 멈춘다. 투사체는 발사 시각부터 첫 프레임을 재생한다.
- 선택·폴백·색 구간·프레임과 PNG 규격은 `tests/sprite-application.test.mjs`, 가로 1행 가공은 `tests/sprite-pipeline.test.mjs`에서 검사한다.

## 보스 표시

보스 규칙은 [적 지침](../Enemy/AGENTS.md)의 '보스'를 따른다.

- 성기사단장은 금색 장식의 은회색 갑주 스프라이트로, 일반 적보다 크게 그려 구분한다. 접촉 공격은 공격 동작, 기술(심판의 낙인·성광 십자·기사단 소집·신성 방벽)은 공통 시전 동작을 재생한다.
- 범위 공격의 경고는 판정에 쓰는 범위 그대로 반투명 빨간색으로 그리고, 경고 시간이 지날수록 진해진다. 피해가 들어가거나 보스가 죽으면 지운다.
- 신성 방벽이 유지되는 동안 보호 범위(보스 중심 반경 160px)를 금색 원으로 표시하고, 같은 지름의 금색 룬 고리 그림을 12fps로 반복한다.
- 낙인·성광 십자 경고가 끝나 피해가 들어가는 순간, 그 자리에 타격 그림을 0.3초 동안 한 번 재생한다. 낙인은 반경 100px 원에 맞추고, 십자는 폭 60px·양쪽 팔 전체 1000px의 광선을 세로·가로로 겹쳐 그린다. 경고 도형은 기존대로 피해 순간에 지운다.
- 보스가 살아 있는 동안 HUD 패널 오른쪽 위의 별도 패널에 이름·체력(현재/최대)과 체력 바(너비 576px)를 표시한다. 화면 위 가운데는 HUD 패널과 겹치므로 쓰지 않는다.
- 보스가 등장하면 화면 위쪽 가운데에 '성기사단장 출현'을 게임 시간 2초 동안 표시한다.
- 보스 보상 선택창은 레벨업 보상 선택창과 같은 배치를 쓰고, 제목('성기사단장 처치 · 보상을 선택하세요')과 구리색 카드 테두리, '보스 보상' 표시로 구분한다. '직업 특수 특기' 카드에는 얻게 될 특기의 이름과 효과를 보여 준다.
- 플레이어의 배리어는 체력 바 바로 위에 하늘색 바(배리어 최대치 기준 비율)로 표시하고, 성스러운 방벽을 얻기 전에는 숨긴다.

## 가호 표시

가호 규칙은 [적 지침](../Enemy/AGENTS.md)의 '가호'를 따른다.

- 가호 선택창은 레벨업 보상 선택창과 같은 배치·입력·오입력 방지를 쓰고, 제목(`2:00 · 가호를 선택하세요`처럼 그 가호가 나온 게임 시간)과 붉은 카드 테두리로 구분한다. 카드 아래 칸에는 '가호 · 중첩 n'을 표시한다.

- **경험치 바:** 위치·크기·색. 체력 바와 구분되는 색을 사용하고 기존 HUD 정보를 가리지 않는다. 현재는 패널 안 체력 바 아래 180×6 파란색 바이며, 체력 바 오른쪽에 `Lv 레벨  현재/필요량`을 표시한다. 적 색상 범례는 그 아래로 옮겼다.
- **보상 선택창:** 배치·카드 내용·입력 방식·오입력 방지 시간. 선택창은 HUD(20000대)와 게임 종료 화면(30000대) 사이 깊이 25000대에 그린다. 카드 문구는 카드 너비 안에서 줄바꿈한다. 현재 값은 아래 표와 같으며 `src/main.ts`에서 관리한다.
- **타이틀·캐릭터 선택 화면:** 배치와 글자 크기. 현재는 제목 64px, 구현 직업 카드 380×340 세 장(간격 24px, 1280px 화면 안), 잠긴 카드 230×76 세 장이다. 게임 제목은 가제다.

## UI 테스트 및 구현 시 확인

- 경험치 획득·레벨업 직후 표시 값이 게임 상태와 일치하는지 확인한다.
- 레벨업 경계에서 경험치 바가 0으로 초기화되거나 초과분만큼 채워지는지 확인한다.
- 체력·경험치 바처럼 값에 따라 길이가 바뀌는 표시는 0·중간·가득인 상태를 실제 화면에서 확인한다. 표시 오류는 콘솔 오류 없이 일어날 수 있으므로 글자 값과 바 길이를 함께 본다.
- 게임 종료 화면의 최종 레벨이 종료 시점의 레벨과 일치하는지 확인한다.
- 보상 선택창의 표시 내용이 게임 상태와 일치하는지, 선택 후 창이 닫히고 HUD 수치(체력 등)가 갱신되는지 확인한다.
- 선택지 3·4·5개일 때 카드가 화면 안에 겹치지 않게 배치되고 숫자키가 표시된 선택지 수까지만 동작하는지 확인한다.
- 선택창이 열린 상태에서 이동 키 입력이 선택이나 플레이어 이동으로 이어지지 않는지 확인한다.
- 카메라가 월드 경계에 있을 때도 HUD 위치가 고정되는지, 기존 체력·처치 표시가 유지되는지 확인한다.
- 휘두르기·폭발 효과 원이 판정 반경과 같은 크기로 그려지고 사라지는지, 마력 폭주 남은 시간이 게임 상태와 일치하는지 확인한다.
- 타이틀 → 캐릭터 선택 → 게임 → 게임 종료 → 캐릭터 선택 흐름과 Esc로 타이틀 복귀가 동작하는지, 고른 직업으로 게임이 시작되는지 확인한다.
- 게임 종료 후 새 게임에서 HUD·적·투사체·선택창 등 이전 게임의 표시가 남지 않는지 확인한다.
- 실제 화면 확인을 하지 못한 경우 보고에 명시한다.
- 워록의 기존 표시 검사는 `tests/warlock-sprite.test.mjs`, 공통 재생·모든 PNG·근접 및 좀비 공격 기록은 `tests/sprite-application.test.mjs`, 캐시·변조 복구·실패 시 보존은 `tests/sprite-pipeline.test.mjs`에서 검사한다. 화면에서는 세 직업의 네 방향 이동, 벽에 막힘, 이동 중 공격, 장애물 앞뒤 가림, 피격, 재시작과 좀비 부활·공격·제거를 확인한다.
