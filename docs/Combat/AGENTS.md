# 전투 시뮬레이션 테스트 지침

[루트 개발 지침](../../AGENTS.md)과 함께 적용한다. 플레이어·적이 공유하는 시간 처리, 이동 충돌 및 투사체 판정 코드를 변경할 때 사용한다. 기능별 수치와 행동은 [플레이어 지침](../Player/AGENTS.md)과 [적 지침](../Enemy/AGENTS.md)을 따른다.

## 프레임 간격과 시간 일관성

- 짧은·긴·불규칙한 프레임 간격으로 같은 총 경과 시간을 주어 비교한다. 게임 시간, 이동량, 공격·생성 주기와 피격 간격이 정한 허용 오차 안에서 일치해야 한다.
- 낮은 FPS로 계속 실행되는 상황과 비활성 탭에서 복귀하는 상황은 별도로 검사한다. 복귀 시 몰아서 실행되는 현상을 막는 처리가 정상 플레이의 경과 시간을 버리지 않아야 한다.
- 타이머의 시작·갱신·중단·재개 및 대상 교체 시점을 검사해 행동이 누락되거나 한꺼번에 누적 실행되지 않는지 확인한다.

## 움직이는 대상과 충돌

- 투사체와 대상이 모두 움직이는 상황을 검사한다. 같은 방향·반대 방향·수직 이동과 빠른 투사체, 대각선·모서리 조건을 포함한다.
- 프레임 중간에는 교차하지만 끝 위치에서는 겹치지 않는 경우에도 유효한 적중을 감지해야 한다. 실제 경로가 교차하지 않는 경우에는 피해가 없어야 한다.
- 비관통 투사체는 이동 경로에서 먼저 맞힌 대상에게만 정확히 한 번 피해를 주는지 확인한다.
- 몸체의 이동 충돌과 투사체의 장애물 통과 규칙을 구분해 검사한다.

## 수명과 타이머 경계

- 수명·재사용 대기·피격 간격은 경계 직전·정확한 경계·경계 직후를 검사하고, 경계 시점의 허용 여부를 명시한다.
- 한 프레임 안에 적중과 수명 종료가 함께 있으면 시간 순서대로 검증한다. 남은 수명 20ms, 적중까지 약 11.4ms, 프레임 간격 50ms인 경우 수명 내 적중 피해가 누락되면 안 된다.
- 만료 후에는 피해가 없어야 하며, 적중·제거된 투사체가 이후 업데이트에서 중복 피해를 주지 않는지 확인한다.
- 화면 밖 이동과 수명 종료를 구분한다. 화면 밖에서도 피해가 가능한 투사체를 카메라 경계에서 제거하지 않는지 확인한다.

## 일시정지와 재개

- 레벨업 보상 선택 등으로 게임이 일시정지되면 서로 다른 프레임 간격으로 시간을 보내도 게임 시간·이동·투사체·생성·공격 간격·피격 간격이 변하지 않는지 확인한다.
- 재개 직후 일시정지 동안의 시간이 한꺼번에 처리되지 않는지 확인한다. 비활성 탭 복귀 처리와 구분해 검사한다.
- 일시정지와 플레이어 사망이 같은 프레임에 겹치면 게임 종료가 우선하는지 확인한다.

## 처치와 보상

- 한 프레임에 여러 투사체가 같은 적을 맞혀 사망시켜도 처치 수는 한 번만 증가하고 경험치 구슬은 하나만 생기는지 확인한다.
- 사망한 적에게 남은 투사체가 맞아도 처치·구슬이 다시 발생하지 않는지 확인한다.
- 플레이어 사망과 구슬 획득이 같은 프레임에 일어나면 게임 종료 후의 경험치 획득이 없는지 확인한다.
- 구슬의 끌어당김 이동과 획득을 서로 다른 프레임 간격에서 같은 총 경과 시간으로 비교한다. 빠른 끌어당김이 프레임 사이에 플레이어를 지나쳐 획득이 누락되거나 지연되지 않아야 한다.
- 획득 반경과 획득 판정은 경계 직전·정확한 경계·경계 직후를 검사하고 경계 시점의 포함 여부를 명시한다.
