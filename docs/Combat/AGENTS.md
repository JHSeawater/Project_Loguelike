# 전투 시뮬레이션 지침

[루트 개발 지침](../../AGENTS.md)과 함께 적용한다. 플레이어·적이 공유하는 시간 처리, 이동 충돌 및 투사체 판정의 현재 값과 테스트 기준을 이 문서에서 관리한다. 기능별 수치와 행동은 [플레이어 지침](../Player/AGENTS.md)과 [적 지침](../Enemy/AGENTS.md)을 따른다.

## 현재 구현 값

전투 시뮬레이션은 `src/battle.ts`, 값은 `src/battle-config.ts`의 `BATTLE_CONFIG`에서 관리한다. 투사체 수치는 초기값이며 플레이 테스트로 조정한다.

| 항목 | 현재 값 | 이유 |
| --- | --- | --- |
| 프레임 진행 | 경과 시간을 50ms 이하 단계로 나눠 모두 진행. 한 프레임 최대 250ms까지만 반영 | 단계 길이에 의존하는 판정(공격·생성 1회, 접촉 검사)을 유지하면서 저프레임의 시간 손실을 막음. 탭 복귀 시 Phaser가 delta를 초기화하고 200ms 초과 delta를 걸러내므로 정상 플레이는 상한에 걸리지 않음 |
| 주기 동작 시점 | 공격·회복·생성의 다음 간격은 이번 단계 안에서 준비된 시각부터 센다. 이전 단계부터 대상이 없거나 사거리 밖이라 기다렸으면 지금부터 센다 | 프레임 간격이 주기로 나누어떨어지지 않아도 늦어진 시간이 쌓이지 않음 |
| 플레이어 투사체 | 700px/초, 8×8, 수명 4초 | 사거리 내 조준 반응과 화면 밖 적중 확인 |
| 적 투사체 | 280px/초, 10×10, 수명 6초. 석궁병 볼트는 500px/초 | 플레이어가 이동으로 피할 여유 확보 |
| 투사체 정리 | 첫 적중·수명 만료·월드 이탈 | 카메라 밖에서 피해를 유지하면서 무제한 누적 방지 |
| 투사체 수명 경계 | 한 프레임 안에서도 남은 수명 동안의 경로만 판정. 만료 시점에 정확히 닿으면 피해 없음 | 프레임 간격과 관계없이 수명 내 적중을 놓치지 않고, 만료를 소멸로 보는 규칙과 일치 |
| 움직이는 대상 판정 | 몸체도 단계 동안 시작 위치에서 끝 위치까지 일정하게 움직였다고 보고, 시작 위치의 몸체에 대한 투사체의 상대 경로로 판정한다. 단계 안에서 꺾인 이동(벽을 따라 미끄러짐 등)도 직선으로 본다 | 단계 중간에만 겹치는 적중을 놓치지 않고 끝 위치에만 겹치는 경우를 맞히지 않아, 프레임 간격과 관계없이 같은 결과 |
| 발사 직후 | 단계 끝에 발사된 투사체는 다음 단계부터 움직인다 | 이동 거리가 속도 × 발사 후 경과 시간과 같고 비행 시간이 수명과 같음 |

## 측정 기록과 한계

- 최대 적 수 근처(실제 맵, 적 89마리)에서 렌더링을 제외한 한 업데이트의 처리 시간은 평균 0.69ms, 상위 5% 1.22ms, 최대 4.15ms였다(Node 22 측정). 실행 환경에 따라 달라지므로 자동 테스트에는 넣지 않고, 생성 수치나 경로 탐색을 바꿀 때 다시 측정해 이 기록을 갱신한다.
- 자동 테스트는 Phaser 화면과 입력을 다루지 않는다. 화면 표시와 입력 동작은 실제 실행으로 별도 확인하고, 자동 검사 결과와 구분해 보고한다.

## 프레임 간격과 시간 일관성

- 짧은·긴·불규칙한 프레임 간격으로 같은 총 경과 시간을 주어 비교한다. 게임 시간, 이동량, 공격·생성 주기와 피격 간격이 정한 허용 오차 안에서 일치해야 한다.
- 주기 동작은 간격을 나누어떨어지게 하지 않는 프레임 간격(60FPS의 약 16.7ms, 30ms, 45ms 등)으로 여러 주기 동안 진행해, k번째 동작이 첫 동작 + k × 간격부터 한 프레임 안에 일어나는지 검사한다. 20ms·100ms처럼 나누어떨어지는 간격만으로는 늦어짐의 누적을 찾지 못한다.
- 낮은 FPS로 계속 실행되는 상황과 비활성 탭에서 복귀하는 상황은 별도로 검사한다. 복귀 시 몰아서 실행되는 현상을 막는 처리가 정상 플레이의 경과 시간을 버리지 않아야 한다.
- 타이머의 시작·갱신·중단·재개 및 대상 교체 시점을 검사해 행동이 누락되거나 한꺼번에 누적 실행되지 않는지 확인한다.

## 움직이는 대상과 충돌

- 투사체와 대상이 모두 움직이는 상황을 검사한다. 같은 방향·반대 방향·수직 이동과 빠른 투사체, 대각선·모서리 조건을 포함한다.
- 프레임 중간에는 교차하지만 끝 위치에서는 겹치지 않는 경우에도 유효한 적중을 감지해야 한다. 실제 경로가 교차하지 않는 경우에는 피해가 없어야 한다.
- 비관통 투사체는 이동 경로에서 먼저 맞힌 대상에게만 정확히 한 번 피해를 주는지 확인한다.
- 몸체의 이동 충돌과 투사체의 장애물 통과 규칙을 구분해 검사한다.
- 이 항목은 `tests/projectiles.test.mjs`에서 검사한다.

## 수명과 타이머 경계

- 수명·재사용 대기·피격 간격은 경계 직전·정확한 경계·경계 직후를 검사하고, 경계 시점의 허용 여부를 명시한다.
- 한 프레임 안에 적중과 수명 종료가 함께 있으면 시간 순서대로 검증한다. 남은 수명 20ms, 적중까지 약 11.4ms, 프레임 간격 50ms인 경우 수명 내 적중 피해가 누락되면 안 된다.
- 만료 후에는 피해가 없어야 하며, 적중·제거된 투사체가 이후 업데이트에서 중복 피해를 주지 않는지 확인한다.
- 화면 밖 이동과 수명 종료를 구분한다. 화면 밖에서도 피해가 가능한 투사체를 카메라 경계에서 제거하지 않는지 확인한다.

## 일시정지와 재개

- 레벨업 보상 선택 등으로 게임이 일시정지되면 서로 다른 프레임 간격으로 시간을 보내도 게임 시간·이동·투사체·생성·공격 간격·피격 간격이 변하지 않는지 확인한다.
- 재개 직후 일시정지 동안의 시간이 한꺼번에 처리되지 않는지 확인한다. 비활성 탭 복귀 처리와 구분해 검사한다.
- 일시정지와 플레이어 사망이 같은 프레임에 겹치면 게임 종료가 우선하는지 확인한다.

## 처치와 보상

- 한 프레임에 여러 투사체가 같은 적을 맞혀 사망시켜도 처치 수는 한 번만 증가하고 경험치 구슬은 한 번만 생기는지 확인한다.
- 사망한 적에게 남은 투사체가 맞아도 처치·구슬이 다시 발생하지 않는지 확인한다.
- 플레이어 사망과 구슬 획득이 같은 프레임에 일어나면 게임 종료 후의 경험치 획득이 없는지 확인한다.
- 구슬의 끌어당김 이동과 획득을 서로 다른 프레임 간격에서 같은 총 경과 시간으로 비교한다. 빠른 끌어당김이 프레임 사이에 플레이어를 지나쳐 획득이 누락되거나 지연되지 않아야 한다.
- 획득 반경과 획득 판정은 경계 직전·정확한 경계·경계 직후를 검사하고 경계 시점의 포함 여부를 명시한다.
