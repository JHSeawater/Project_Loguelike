# 레벨업 보상 설계

레벨업 보상 선택지 기능의 설계 문서다. 확정 규칙은 각 분야 지침에도 반영했다. '보류 항목'과 이 문서에 없는 보상·성장 기능은 임의로 구현하지 않는다.

관련 문서: [경험치 설계](Experience.md) · [플레이어](Player/AGENTS.md) · [전투 테스트](Combat/AGENTS.md) · [UI](ui/AGENTS.md)

## 확정 규칙

### 선택창과 진행

- 레벨이 오르면 게임이 일시정지되고 화면 중앙에 보상 선택창이 열린다.
- 일시정지 중에는 게임 시간·플레이어와 적의 이동·투사체·경험치 구슬·적 생성·공격 간격·피격 간격 타이머가 모두 멈춘다.
- 플레이어가 선택지 하나를 고르면 효과가 즉시 적용되고 창이 닫히며 게임이 이어진다.
- 반드시 하나를 골라야 하며 다시 뽑기·건너뛰기는 없다.
- 보상은 이번 게임에서만 유지되며, 새로고침으로 다시 시작하면 초기 능력치로 돌아간다.
- 게임 종료 후에는 레벨업과 보상 선택이 일어나지 않는다. 레벨업과 플레이어 사망이 같은 프레임에 일어나면 게임 종료가 우선한다.

### 선택지 구성

- 선택지는 기본 3개이며, '선택지 추가' 보상으로 최대 5개까지 늘어난다.
- 최대 중첩에 도달하지 않은 보상 중에서 중복 없이 같은 확률로 무작위로 고른다.
- 고를 수 있는 보상이 선택지 수보다 적으면 남은 보상만 보여준다. 체력 회복은 최대 중첩이 없으므로 항상 후보에 남는다.
- 보상 목록은 모든 플레이어가 공통으로 사용한다.

### 연속 레벨업

- 한 번에 여러 레벨이 오르면 오른 레벨 수만큼 선택창을 순서대로 띄운다.
- 선택창마다 그 시점의 보상 상태(중첩 수·선택지 수)로 새로 무작위 선택지를 구성한다. 앞 선택창에서 고른 '선택지 추가'는 바로 다음 선택창부터 적용된다.

### 표시

- 선택창의 각 보상에 이름·1회 효과·현재/최대 중첩(예: 2/5)을 표시한다.
- HUD에는 보유 보상 목록을 표시하지 않는다.

## 보상 목록

증가 방식은 기본값 기준 고정 증가량을 더하는 방식이다. 효과량과 최대 중첩은 플레이 테스트로 조정한다.

| 보상 | 1회 효과 | 최대 중첩 | 최대 중첩 시 값 |
| --- | --- | --- | --- |
| 공격력 강화 | 공격력 +2 | 10 | 30 |
| 공격 속도 강화 | 공격 간격 −0.05초(기본값의 10%) | 5 | 0.25초(초당 4회) |
| 최대 체력 강화 | 최대 체력 +20, 현재 체력도 +20 | 10 | 300 |
| 이동속도 강화 | 이동속도 +25px/초(기본값의 10%) | 5 | 375px/초 |
| 투사체 속도 강화 | 투사체 속도 +105px/초(기본값의 15%) | 3 | 1015px/초 |
| 획득 반경 확대 | 획득 반경 +25px | 5 | 225px |
| 선택지 추가 | 레벨업 선택지 수 +1 | 2 | 5개 |
| 체력 회복 | 현재 최대 체력의 30% 회복(최대 체력 초과 불가) | 제한 없음 | — |

- 기본값: 최대 체력 100, 공격력 10, 공격 간격 0.5초, 이동속도 250px/초, 투사체 속도 700px/초, 획득 반경 100px, 선택지 3개.
- 이동속도 최대치 375px/초도 경험치 구슬 끌어당김 속도 450px/초보다 느리므로 구슬 획득 규칙은 유지된다.
- 공격 간격 최소치 0.25초에서도 투사체는 한 번에 1개이며 비유도·비관통 규칙을 유지한다.
- 피격 간격 3초는 보상으로 바꾸지 않는다.

## 보류 항목

아래 항목은 이번 단계에서 구현하지 않으며, 사용자 결정 후 규칙으로 옮긴다.

- **투사체 수·관통 보상:** 플레이어 지침의 '한 번에 1개 발사·비관통' 규칙을 바꾸는 보상이다. 추가할 때 여러 발의 발사 각도와 관통 시 같은 적 중복 타격 방지 규칙을 함께 정한다.
- **다시 뽑기·건너뛰기:** 선택지를 다시 뽑거나 선택을 건너뛰는 기능.
- **직업별 보상:** 직업 설계 시 직업별 보상 목록 사용 여부를 정한다.

## 구현 시 초기 설정 항목

확정 규칙에 따라 아래 초기값으로 구현했으며 플레이 테스트로 조정한다. 보상 이름·효과량·최대 중첩과 선택지 구성은 `src/rewards.ts`, 일시정지와 선택 처리는 `src/battle.ts`, 선택창 표시는 `src/main.ts`에서 관리한다.

| 항목 | 초기 설정 | 이유 |
| --- | --- | --- |
| 선택창 배치 | 화면 중앙에 어두운 반투명 배경과 가로로 나란한 카드. 카드 220px 너비, 20px 간격으로 가운데 정렬 | 선택지 5개(1,180px)까지 1280px 화면 안에 들어감 |
| 카드 내용 | 번호, 보상 이름, 1회 효과, 현재/최대 중첩 | 선택 전 효과와 남은 중첩을 비교 가능 |
| 입력 | 마우스 클릭과 숫자키 1~5(표시된 선택지 수까지) | 이동 키와 겹치지 않으며 키보드만으로도 진행 가능 |
| 오입력 방지 | 선택창이 열린 직후 0.3초(실제 시간) 동안 입력 무시. 대기 중 누른 숫자키는 소비되어 나중에 선택되지 않음 | 이동·연속 입력 중 의도치 않은 선택 방지 |
| 선택창 제목 | `레벨 N 달성 · 보상을 선택하세요`. 연속 레벨업은 앞선 레벨부터 표시 | 몇 번째 보상 선택인지 구분 |
| 무작위 생성 | 전투의 기존 난수 함수 사용 | 테스트에서 난수를 고정해 선택지 구성을 재현 |
| 표시 | 외부 이미지 없이 코드로 그린 사각형과 글자 | 기존 UI 방침 유지 |

## 구현 시 검증 계획

- 각 보상의 1회 효과와 최대 중첩 시 값이 표와 일치하는지, 최대 중첩 이후 다시 나오지 않는지 검사한다.
- 최대 체력 강화 시 현재 체력도 증가하고, 체력 회복이 최대 체력을 넘지 않는지 검사한다.
- 고정 난수로 선택지가 중복 없이 구성되는지, 후보가 부족할 때 남은 보상만 나오는지, 체력 회복이 항상 후보에 남는지 검사한다.
- 선택지 추가 보상으로 선택지가 3 → 4 → 5개가 되고 5개를 넘지 않는지, 바로 다음 선택창부터 적용되는지 검사한다.
- 일시정지 중에는 서로 다른 프레임 간격으로 시간을 보내도 게임 시간·이동·적·투사체·구슬·생성·공격·피격 간격 타이머가 변하지 않는지 검사한다.
- 선택 직후 진행이 재개되고, 일시정지 동안의 시간이 몰아서 처리되지 않는지 검사한다.
- 연속 레벨업 시 오른 레벨 수만큼 선택이 이어지고, 선택이 끝나기 전 추가 레벨업도 누락되지 않는지 검사한다.
- 레벨업과 플레이어 사망이 같은 프레임에 일어나면 게임 종료가 우선하고 선택창이 열리지 않는지 검사한다.
- 공격 간격·이동속도·투사체 속도·획득 반경 강화 후 기존 전투·이동·충돌·구슬 획득 테스트가 새 값에서도 유지되는지 확인한다.
